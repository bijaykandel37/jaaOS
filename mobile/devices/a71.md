# jaaOS Mobile on the Samsung Galaxy A71 (SM-A715F, codename `a71`)

Facts below were checked on 2026-11-22 against the official pages:
wiki.lineageos.org/devices/a71, its install and quirks pages, the LineageOS download API, and
doc.e.foundation/devices/a71.

- **Official LineageOS 23.2 (Android 16)**, weekly builds (latest seen: 2026-11-18), maintainer
  Haky86. Also a community **/e/OS** build (Android 16, de-Googled LineageOS with microG).
- Supported models (exact match): **SM-A715F, SM-A715F/DS, SM-A715F/DSN, SM-A715F/DSM**. The
  A71 5G (SM-A716*) is **not** supported: never flash these files on it.
- Samsung's own firmware for this phone stopped at Android 13 (One UI 5.1).

## Stay on Samsung, or switch? (decide this first)

| | Stock Samsung + `jaa-debloat` (path A) | LineageOS 23.2 (path B) |
|---|---|---|
| Android version | 13 (Samsung updates for the A71 have ended) | **16, with current security patches every week** |
| Google | removed by `jaa-debloat` (reversible) | none at all (add microG via /e/OS if you need push notifications) |
| Camera | **every Samsung mode and processing** | open-source camera app: fewer modes, plainer photos |
| Calls | VoLTE + Wi-Fi calling work | **no VoLTE / Wi-Fi calling**: calls fall back to 2G/3G. If your carrier has switched those off, **calls will not work** |
| Banking / payment apps | work | apps that require Play Integrity may refuse to run |
| Knox | intact (Secure Folder, Samsung Pass) | **tripped forever** when you unlock: Secure Folder and Samsung Pass/Wallet are gone, even if you go back |
| Two PINs → two workspaces | Secure Folder | Android users or a work profile (below) |
| Risk | none (reversible, no unlock) | unlocking wipes the phone. A wrong file or the wrong model can brick it |

**Rule of thumb:** if your carrier still runs 2G/3G and you can live without Samsung's camera
processing and Play-Integrity banking apps, LineageOS gives you a *safer* phone (Android 16 +
patches) than stock Android 13 without updates. Otherwise, stay on stock and debloat.

## Path A — stock, de-Googled (no unlock)

```bash
mobile/debloat/jaa-debloat check
```

```bash
mobile/debloat/jaa-debloat plan --tier standard
```

```bash
mobile/debloat/jaa-debloat apply --tier standard
```

Two workspaces: **Secure Folder** (Settings > Security and privacy > More security settings >
Secure Folder), with a different PIN/pattern from the lock screen. See `docs/11-mobile.md`.

## Path B — LineageOS 23.2

### 1. Pre-flight (read-only, changes nothing)

```bash
mobile/debloat/jaa-debloat rom-check
```

It checks the exact model, that the **stock firmware is Android 13** (LineageOS requires it as
the base), that **OEM unlocking** is allowed, that **no Google account** is on the phone (or the
phone locks itself after the wipe: factory reset protection), and that the battery is at least
50%. It prints `READY` only when all of these pass.

Back up photos, contacts and 2FA codes now: **step 2 wipes the phone.**

### 2. Install (manual, from the official guide)

`jaa-debloat` deliberately flashes nothing. Follow **https://wiki.lineageos.org/devices/a71/install/**
step by step, on a computer with `adb` and the flasher **samloader-rs** that the wiki links. In short:

1. Developer options > **OEM unlocking** on. Download mode: phone off, hold **Volume Up + Volume
   Down** and plug in USB. Choose "Device unlock mode" / "Unlock bootloader" (this wipes the phone).
2. Download the wiki's `vbmeta.img`, go back to download mode, and flash it:

   ```bash
   samloader flash --partition VBMETA vbmeta.img
   ```

   Let the phone factory-reset, skip setup, then check OEM unlocking is still on.
3. Download **Lineage Recovery** (`recovery.img`) from the download page, go to download mode, and:

   ```bash
   samloader flash --partition RECOVERY recovery.img --no-reboot
   ```

   Then reboot **straight into recovery**: hold Volume Down + Power until the screen goes black,
   then immediately Volume Up + Power. If you boot stock instead, it overwrites the recovery.
4. In Lineage Recovery: Factory reset > **Format data**, then Apply update > Apply from ADB, and
   on the computer (use the exact file name you downloaded):

   ```bash
   adb -d sideload lineage-23.2-20261118-nightly-a71-signed.zip
   ```

5. Optional, **before the first boot**: if you need push notifications in apps that use Google's
   service, install **microG** following the wiki's microG page (linked from the install guide),
   or use **/e/OS** instead, which includes microG. Plain LineageOS has no Google at all.
6. Reboot ("Reboot system now"). The first boot can take up to 15 minutes. To keep firmware (modem, bootloader) current later, the wiki's
   "Update to a newer vendor firmware version" page applies.

### 3. Two PINs → two workspaces on LineageOS

- **Separate users** (strongest separation): Settings > System > **Multiple users** > add a
  user, then set its own PIN/pattern. Each user gets its own file-based-encryption key. At the
  lock screen, tap the user icon, pick the workspace, and enter its PIN. If the official build
  hides the Multiple users menu, a self-built jaaOS image adds `mobile/rom/overlay` to enable it.
- **Work profile** (always available): install **Shelter** from F-Droid. It creates a second
  workspace (a work profile) with its own apps. Then Settings > Security > **"Use one lock" off**
  gives the work profile its own PIN/pattern.

Same honest limits as everywhere in jaaOS (`docs/11-mobile.md`): each workspace's **contents** are
protected while locked. The second workspace is hidden only from casual inspection: it shows in
Settings and to forensic tools. It is no defence against malware with system access, or against
being forced to unlock it. An unlocked bootloader also means someone holding the phone can flash
other software (your data stays encrypted, but the phone itself is not tamper-proof).

## Going back to stock

Download the latest Samsung firmware for your exact model and flash it with samloader-rs (the
wiki's "Update to a newer vendor firmware version" page shows how). Knox stays tripped, permanently.

Do not run `jaa-debloat apply` on LineageOS: it has no bloat, and LineageOS warns that removing
system apps can break it. The tool refuses on LineageOS.
