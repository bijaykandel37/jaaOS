# jaaOS Mobile

De-Google a Samsung phone and set up two PIN-protected workspaces. Read
[`../docs/11-mobile.md`](../docs/11-mobile.md) first: it explains what is possible on Samsung
(camera features, bootloader, Knox) and the two paths.

```bash
mobile/debloat/jaa-debloat check
```

```bash
mobile/debloat/jaa-debloat plan --tier standard
```
